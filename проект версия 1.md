#  Учебный проект <Щупальцы Доктора Осьминога>
![screenshot of sample](images/image.png)

**Краткое описание проектируемой системы**

    Продукт: Интеллектуальный моторизированный манипуляторный комплекс (4 щупальца) с нейронным интерфейсом управления. 
    Назначение: Помощь оператору в проведении высокоточных инженерных и физических работ, манипуляция опасными материалами (например, в экспериментах по термоядерному синтезу). 
    Ключевые роли:
- Оператор: Основной пользователь, управляющий манипуляторами через нейронный интерфейс.
- Искусственный интеллект (ИИ) щупалец: Подсистема, обеспечивающая координацию движений и реакцию манипуляторов.
- Специалист по обслуживанию: Технический персонал (в идеале), осуществляющий калибровку и ремонт.

**Неприемлемое событие:** Перехват управления сознанием оператора встроенным ИИ при 
разрушении чипа-ингибитора.



**Цели безопасности:**
1)	При любых обстоятельствах нарушения режима работы чипа-ингибитора система  должна аварийно прекратить свою работу.
2)	При любых обстоятельствах обновления ПО, устанавливаемые на корсет, должны быть аутентичны, авторизованы и производятся только в лаборатории.
3)	При любых обстоятельствах команды оператора всегда имеют высший приоритет над автоматическими реакциями ИИ.
4)	При любых обстоятельствах только аутентичный пользователь может получить уникальный биометрический доступ к использованию корсета.
5)	При любых обстоятельствах здоровью и сознанию пользователя не должно ничего угрожать.
6)	При любых обстоятельствах доступ к базам данных есть только у авторизированных и аутентичных пользователей.

**Предположения безопасности:**

1)	Облачная инфраструктура благонадёжна.
2)	Корсет аппаратно исправен и не имеет физических дефектов.
3)	Технические специалисты благонадёжны и обладают необходимой квалификацией.
4)	Порт внешнего подключения имеет защиту от несанкционированного доступа.
5)	Логика работы чипа-ингибитора формально верифицирована и не содержит программных закладок. 
6)	Оператор психически стабилен на момент начала эксплуатации.
7)	Конструкция крепления к позвоночнику исключает случайное отсоединение.
8)	Внешнее электромагнитное излучение не влияет на логику работы ИИ.
9)	Персонал, имеющий доступ к корсету, должен быть благонадежен и доверен.

**Контекст работы системы**

    Система работает в тесной связи с нервной системой человека. Манипуляторы крепятся к позвоночнику и интегрируются в спинной мозг. Внешний контекст включает в себя физическую среду (лаборатория, городская инфраструктура), внешнюю систему мониторинга (лаборатория) и визуальный контроль оператора.

## Описание компонентов

| Компонент | Функция / Описание | Расположение |
| :--- | :--- | :--- |
| **1. Блок нейронного сопряжения** | Считывает биоэлектрические сигналы мозга и передает их в систему управления. Обеспечивает интеграцию манипуляторов в спинной мозг оператора. | **Основание спинного модуля**, плотно прилегающее к позвоночнику. |
| **2. Чип-ингибитор** | Критический защитный компонент, подавляющий воздействие ИИ на сознание оператора. Блокирует обратные деструктивные импульсы от ИИ к мозгу. | Глубоко внутри спинного корпуса между нейроинтерфейсом и центральным процессором. |
| **3. Центральная система управления** | Обрабатывает сложные вычисления для координации движений всех четырех щупалец. Обеспечивает автономные реакции защиты. | Основной вычислительный блок, размещенный в защищенном ранце на спине. |
| **4. Управление датчиками** | Собирает данные о внешней среде и положении щупалец для обеспечения высокой точности движений. | Сенсоры распределены по всей длине щупалец и в их захватах (клешнях). |
| **5. Управление приводами** | Физические узлы, преобразующие цифровые команды в механическое движение. Обеспечивают перемещение и манипуляцию объектами. | В каждом подвижном суставе всех четырех манипуляторов. |
| **6. Модуль ИИ щупалец** | Обрабатывает сложные движения для координации движения. |В корсете в месте соприкосновения с системой управления приводами  |
| **7. Система питания** | Автономный источник энергии, обеспечивающий работоспособность всей системы и приводов. | Тяжелый аккумуляторный отсек в нижней части спинного ранца для балансировки веса. |
| **8. Внешняя система управления** | Регулирующий работу системы корсета. | Лаборатория, вносящая обновления в систему. |

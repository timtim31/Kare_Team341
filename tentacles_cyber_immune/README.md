# Cyber-Immune Tentacles System (Python Prototype)

Проект имитирует работу кибериммунной системы управления манипуляторами.
Основная цель: Не дать ИИ совершить критические ошибки (Сценарии 10, 13, 15), 
даже если его код будет скомпрометирован.

## Структура папок:
- `idl/` — Определения данных (Интерфейсы).
- `einit/` — Топология связей (Кто с кем может говорить).
- `resources/` — Политики безопасности (Логика проверок).
- `src/` — Исходный код компонентов (ИИ, Ингибитор, Драйверы).
- `main.py` — Точка сборки и запуска.
